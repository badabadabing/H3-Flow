# 100 名视频创作者合成可用性审计

日期：2026-08-12

## 研究边界

这不是 100 名真实用户访谈，也不是产品遥测。它是一组可复现的合成任务审计：把 100 个创作者角色分配到固定创作目标、技术熟练度、时长、画幅、参考素材和交付压力，再逐一检查当前界面是否让其明确知道下一步、错误原因和恢复路径。

“影响人数”表示有多少个合成任务会经过该阻力点，不表示真实用户投诉率或市场统计结论。

## 设计与产品升级原则

- 第一视口只表达一件事：写创意，系统负责工作流。
- 主路径固定为“创意简报 → 分镜节拍 → 交付质量 → 生成总检”。
- 错误必须同时回答“为什么”“先修什么”“去哪里修”。
- 技术信息用于建立信任，但不与创作决策争夺第一层级。
- 所有自动保存都保持本机；API Key、参考图字节和硬件快照不进入草稿。
- 长视频继续诚实标注为末帧续接与局部剧情隔离，不宣传为无缝生成。

## 当前证据与限制

审计基线和升级后截图位于本地 `output/playwright/cohort-audit/`，不提交到公开仓库。浏览器验证覆盖 1440×1000 和 390×844、空白创意、30 秒分镜阻断、提示词编导弹窗、草稿恢复和生成前总检。

截图和自动化可以验证层级、重排、状态、键盘焦点和错误恢复路径，但不能替代真实创作者对生成质量、文案理解和长期工作流效率的判断。下一轮真实招募应至少覆盖 8–12 名创作者，并记录首次完成时间、主动求助次数、分镜门禁修复率和生成前放弃率。
