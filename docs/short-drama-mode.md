# AI 短剧模式

AI 短剧模式把一个主题转换为可审阅、可导出、可逐镜头交给 H3 的结构化制片包。它是短剧生产链的规划与交接阶段，不会在生成剧本时调用 ComfyUI，也不会把“写好了制片包”描述成“生成好了整季视频”。

## 使用方法

1. 在顶栏切换到“AI 短剧”。
2. 填写主题、类型、集数、单集时长、主要角色数、画幅、对白语言与视觉风格。
3. 展开“服务地址、模型与 API Key”，使用自己的 DeepSeek 或其他 OpenAI-compatible 服务。远程服务必须使用 HTTPS；本机 `127.0.0.1` 服务可使用 HTTP。
4. 点击“生成完整制片包”。模型输出会先经过本地结构、ID、引用、镜头数量、五秒节拍和逐集时长复检；第一次不合格时只进行一次定向修复。
5. 在“总览 / 资产圣经 / 分集与镜头”中审阅结果。点击某个镜头的“送入 H3 工作台”，会把该镜头的 5 秒节拍、声音、对白与连续性锚点写入单条视频工作台，但不会自动排队。
6. 可导出完整 JSON 或适合阅读与协作的 Markdown 制片文档。

## 当前生产合同

- 一次支持 1–8 集，每集 30、60、90 或 120 秒，主要角色 1–6 人。
- 每个 H3 镜头只能为 5、10 或 15 秒，并且必须由无缺口的五秒节拍覆盖。
- 角色、服装状态、道具、场景、分集、场次和镜头都使用稳定 ID；所有引用必须解析到已存在资产。
- 本地校验会强制每集镜头总时长等于用户选择的单集时长，不能通过减少集数或偷减时长绕过。
- 短剧草稿和制片包保存在当前浏览器的本机存储；API Key、模型服务地址、参考图、本机路径、硬件、模型清单和工作流不会进入草稿。
- AI 输出属于创作草案，用户仍需审阅版权、事实、表演安全与平台合规性。

## 整季生成为什么仍然锁定

当前版本可以逐镜头交接，但不会自动把整季提交到 ComfyUI。角色与服装一致性要先建立真实参考资产，样片要通过身份、画面轴线、道具状态、声画节奏和接缝检查，本机还要通过模型、节点、显存、存储与队列预检。只有这些环节得到实机证据后，整季批量生成才会开放。

这条门禁避免两类假完成：模型写出了一整季文本，却没有可执行资产；前端一次提交大量任务，却在中途因显存、插件或模型差异失败。

## API

- `GET /api/short-drama`：返回结构版本、范围、模型默认值、隐私说明以及当前功能门禁，不返回 API Key。
- `POST /api/short-drama/plan`：调用用户选择的模型服务，返回通过本地校验的结构化制片包；不会调用 ComfyUI `/prompt`。

请求中的 `api_config.api_key` 只存在于当前 HTTP 请求与模型调用内存中，不会写入项目文件、浏览器草稿或 API 响应。

默认 DeepSeek 路径按照其官方 JSON Output 要求同时设置 `response_format: {"type": "json_object"}`、在提示词中明确 JSON 合同并预留足够的输出长度；模型返回后仍以 H3 Flow 的本地生产规则为最终门禁。参考：[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode) 与 [Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion)。
