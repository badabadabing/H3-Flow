# AI 短剧模式

AI 短剧模式把一个主题转换为可审阅、可导出的结构化制片包。生成剧本时不会调用 ComfyUI；用户确认主要角色参考图后，可一次点击把全部镜头交给后台串行队列，不再逐镜头切换页面。

## 使用方法

1. 在顶栏切换到“AI 短剧”。
2. 填写主题、集数和单集时长。题材与视觉风格可交给 AI 自动判断、选择预设或追加自定义要求。
3. 展开“服务地址、模型与 API Key”，使用自己的 DeepSeek 或其他 OpenAI-compatible 服务。若已在单视频的“AI 提示词编导”中填写，短剧模式会复用同一份本页临时配置并显示“本页内存已就绪”；它不会写入浏览器存储。远程服务必须使用 HTTPS；本机 `127.0.0.1` 服务可使用 HTTP。
4. 点击“生成剧本与角色方案”。模型输出会先经过本地结构、ID、引用、镜头数量、五秒节拍和逐集时长复检；第一次不合格时只进行一次定向修复。
5. 在“总览 / 资产圣经 / 分集与镜头”中按需审阅结果；无需再把镜头逐个送到另一个页面。
6. 给每个主要角色补齐正面、3/4 侧面和全侧面三视图，再点击“确认三视图并锁定”。三张图按同一 Subject 真实上传到本机 ComfyUI `input`，不会发送给编剧模型。
7. 点击“一键生成全部镜头”。系统先检查方案、角色批准、模型、节点、内存、显存和队列，再在后台一次生成一个 5 秒单元。
8. 全部镜头完成后，系统会按分集顺序自动合成整集 24fps MP4；结果区优先显示“播放整集”，同时保留每个分镜用于复核或返修。也可导出 JSON 或 Markdown 制片文档。

## 当前生产合同

- 一次支持 1–8 集，每集 30、60、90 或 120 秒，主要角色 1–6 人。
- 新方案默认把每个 H3 镜头规划为 5 秒。旧制片包中的 10/15 秒镜头会由后台自动拆成连续的 5 秒执行单元，用户无需手动处理。
- 角色、服装状态、道具、场景、分集、场次和镜头都使用稳定 ID；所有引用必须解析到已存在资产。
- 每位主要角色需要正面、3/4 侧面、全侧面三张独立参考图；缺任一视角都不能锁定角色或启动整剧。后端按同一 Subject 顺序把三张图接入 Ref2VA，而不是把它们当成三个人。
- MiniMax H3 当前节点最多接收 9 张参考图，因此三视图模式限制同一场景最多 3 位主要角色；超过时会在提交前阻止，而不是运行到显存阶段再失败。
- 本地校验会强制每集镜头总时长等于用户选择的单集时长，不能通过减少集数或偷减时长绕过。
- 主题、暂定剧名、类型、视觉风格、目标观众、对白语言、集数、单集时长、主要角色数、画幅、结尾方式、对白密度和质量档位全部作为编剧提示词硬约束；本地输出还会把关键约束写入每个 H3 镜头简报。
- 短剧草稿和制片包保存在当前浏览器的本机存储；API Key、模型服务地址、参考图、本机路径、硬件、模型清单和工作流不会进入草稿。
- AI 输出属于创作草案，用户仍需审阅版权、事实、表演安全与平台合规性。

## 一键生成的真实边界

当前版本已经支持确认主要角色后一次点击生成全部镜头并自动合成每集成片。后台只允许一个短剧批次，同时只向 ComfyUI 提交一个 5 秒 H3 单元；每个单元完成并释放资源后才继续。单元失败只自动重试一次，再失败会停止整批任务，保留已经完成的镜头。

这仍不等于“整季发布级成片已经自动交付”。当前未实现桥接服务重启后的断点恢复、自动角色 / 场景 / 道具一致性评分、自动字幕 / 配音装配与发布级质量验收。页面按钮因此仍准确命名为“一键生成全部镜头”，而不是“一键发布整部短剧”。

## API

- `GET /api/short-drama`：返回结构版本、范围、模型默认值、隐私说明以及当前功能门禁，不返回 API Key。
- `POST /api/short-drama/plan`：调用用户选择的模型服务，返回通过本地校验的结构化制片包；不会调用 ComfyUI `/prompt`。
- `POST /api/short-drama/batch/preflight`：只读检查生成门禁，不提交 ComfyUI。
- `POST /api/short-drama/batch/start`：通过门禁后启动后台串行队列。
- `GET /api/short-drama/batch/{job_id}`：读取镜头级进度、错误与本机成片链接。

请求中的 `api_config.api_key` 只存在于当前 HTTP 请求与模型调用内存中，不会写入项目文件、浏览器草稿或 API 响应。

默认 DeepSeek 路径按照其官方 JSON Output 要求同时设置 `response_format: {"type": "json_object"}`、在提示词中明确 JSON 合同并预留足够的输出长度；模型返回后仍以 H3 Flow 的本地生产规则为最终门禁。参考：[DeepSeek JSON Output](https://api-docs.deepseek.com/guides/json_mode) 与 [Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion)。
